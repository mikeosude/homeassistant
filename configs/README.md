# Configuration Files

This directory contains documentation and notes about Home Assistant configuration files.

> **Note:** Do not commit actual `secrets.yaml` or any files containing passwords, tokens, or API keys.

## Key Configuration Files

| File | Purpose |
|------|---------|
| `configuration.yaml` | Main HA configuration |
| `automations.yaml` | Automation definitions |
| `scripts.yaml` | Script definitions |
| `scenes.yaml` | Scene definitions |
| `secrets.yaml` | **Never commit** — stores credentials |
